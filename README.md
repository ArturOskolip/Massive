# Лабораторна робота: Обробка масивів та алгоритми (Python)

Проект містить виконання базових завдань з обробки одновимірних масивів (списків Python), а також симуляцію системи ігрового інвентарю для RPG.

## 📌 Опис функціоналу

* **Завдання 1–8:** Базові алгоритми пошуку, фільтрації, конкатенації, обміну екстремумів та розрахунку середніх значень у масивах.
* **Додаткове завдання:** Система RPG-інвентарю на 10 слотів з функціями додавання, видалення та ущільнення списку (зсув предметів на початок).

## 🚀 Запуск

Переконайтеся, що встановили **Python 3.10+**.

```bash
python main.py
